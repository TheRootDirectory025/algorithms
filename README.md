# Algorithms & Data Structures

A collection of algorithms and data structures
implemented mainly in C++ for software engineering
and technical interview preparation.

## Topics

- Complexity Analysis
- Arrays & Strings
- Linked Lists
- Stack & Queue
- Hash Tables
- Sorting & Searching
- Recursion & Backtracking
- Trees
- Heaps
- Graphs
- Greedy Algorithms
- Dynamic Programming
- Bit Manipulation

## Languages

- C++ — Primary
- Python — Secondary

## Goal

Build strong problem-solving and algorithmic thinking
skills for Software Engineering interviews.
